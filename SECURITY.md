# Security policy

Report vulnerabilities privately through GitHub Security Advisories when available. Do not open a public Issue containing exploit details, credentials, private artwork, personal information, or unpublished provenance records.

This public kit runs locally and should not upload images. Treat any fork that adds network calls as a separate security and privacy surface. Never commit secrets, model-provider keys, private rubrics, or confidential datasets.

For artist-safety, impersonation, doxxing, non-consensual imagery, or rights concerns without an exploitable software flaw, use the artist-rights Issue form but disclose only the minimum public information needed.
