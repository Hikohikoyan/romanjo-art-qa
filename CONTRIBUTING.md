# Contributing

Contributions are welcome from artists, critics, curators, researchers, designers, and engineers.

Use the matching Issue form before opening a substantial pull request. Submit rights-cleared artwork, propose benchmark cases with expected evidence and failure modes, improve public schema wording or accessibility, report false positives, or join the artist and critic reviewer network.

You must have authority to share any submitted image or provide a lawful public reference. State the license and consent scope. Opening an Issue does not transfer artwork copyright or grant model-training permission. Contributors license code and documentation contributions under AGPL-3.0; submitted artwork retains its stated rights.

Do not include credentials, private datasets, personal data, unpublished client work, proprietary prompts, private evaluation rules, model weights, commercial MCP code, or training infrastructure.

Label measured evidence, heuristic inference, and interpretation separately. Similarity is a retrieval lead, not an authorship or infringement finding. Named or sponsored benchmark tracks must disclose conflicts of interest.
